# WEBSITETAMS

Personal website, journal and portfolio of Aamir Mehtab Sheikh, live at https://theaamirsheikh.com.

- Plain HTML, CSS and JavaScript with no framework. The site lives at the repo root and Netlify publishes the root.
- Pages: `index.html`, `purpose.html` (Story), `struggles.html`, `skills.html` + `skills/`, `projects.html` (Work), `inspirations.html`, `services.html`, `404.html`, `90-day-progress/`.
- Styles and scripts live in `assets/css/style.css` and `assets/js/main.js`. Optimised videos, posters and images live in `assets/media/` and `assets/img/`.
- To edit the content in one place, change `_build/build.py` and run `python3 _build/build.py` to regenerate the pages.
- Raw source videos stay on the computer in `_source_media/` and are git-ignored because they are too big for GitHub.
